# 桃園市龍山國小之校園安全時光機 Episode 2

以真實法院判決改編的 3D 校園安全教育遊戲。學生在校園中走到指定地點，進入第一人稱情境：先被小惡魔驅使犯錯、看見後果與判決，再由小天使讓時光倒轉，自己做出選擇。

情境依真實判決改編，人物為虛構。

## 放上 GitHub Pages

1. 在 GitHub 建立一個新的 repository（例如 `safe-time-machine`），設為 Public。
2. 把這個資料夾裡的**所有檔案和資料夾**上傳到 repository 的最上層（`index.html` 要在最上層）。
   - 網頁上傳一次最多 100 個檔案，這個專案不到 20 個，一次就能傳完。
   - `.nojekyll` 是隱藏檔，請一起上傳；沒傳到也不影響遊戲。
3. 到 Settings → Pages，Source 選「Deploy from a branch」，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
4. 等一兩分鐘，網址會是 `https://你的帳號.github.io/safe-time-machine/`。

遊戲需要網路：3D 引擎（three.js、three-vrm）和字型是從 CDN 載入的。

## 檔案說明

| 路徑 | 內容 |
|---|---|
| `index.html` | 整個遊戲（程式、介面、音樂音效、校園全景照片都在裡面） |
| `vrm/*.txt` | 6 個 VRoid 角色模型（壓縮後轉成文字檔） |
| `voice/all.txt` | 全部台詞的預錄語音（一個 mp3 轉成文字檔） |
| `voice/map.txt` | 每句台詞在音檔裡的起點、長度和嘴型資料 |
| `voice-project/桃園市龍山國小之校園安全時光機 Episode 2.voiceproj.json` | 語音專案檔：全部 86 句台詞、9 個角色的音色、情緒指令、兒童音色後製設定，給手機 App「語音工作室」使用 |

`vrm` 檔案對應的角色：`me_b` 主角男生、`me_g` 主角女生、`xiaoyu` 小宇、`xiaokai` 小凱、`xiaomei` 小美、`teacher` 王老師。

## 重新製作語音（手機 App「語音工作室」）

遊戲的語音用 Android App「語音工作室」在手機上離線產生（Qwen3-TTS 模型，有情緒、不需要額度）。
App 與規格書：https://github.com/RFPSCode/voice-studio-app

1. 手機安裝 App（Releases → latest 下載 APK），在「模型」分頁下載模型（只要一次）。
2. 把 `voice-project/桃園市龍山國小之校園安全時光機 Episode 2.voiceproj.json` 傳到手機，在 App 的「專案」分頁匯入；
   或用「從網址匯入」貼上這個檔案在 GitHub 上的網址。
3. 「錄音」分頁 →「產生未完成的句子」。每句可以多產生幾個版本挑最好的；小孩角色的音色在「角色」分頁調整。
4. 「匯出到下載資料夾」→ 手機的 `Download/語音工作室/campus-safety-time-machine/` 會有 `all.txt` 和 `map.txt`。
5. 套用到遊戲，兩種方式擇一：
   - **只在這支手機／平板上用**：開啟遊戲，在開始畫面最下方按「🎙 匯入語音」，同時選 `all.txt` 和 `map.txt`。語音存在這個瀏覽器裡，不用改網站；按「還原內建語音」可以換回來。
   - **讓所有學生都用新語音**：把 `all.txt`、`map.txt` 上傳到 GitHub repository 的 `voice/` 資料夾，蓋掉舊檔。

還沒錄好的句子，遊戲會自動改用裝置朗讀。

### 修改台詞

台詞的 key 是「角色代號|台詞文字」，遊戲和專案檔的台詞文字必須完全一樣才找得到語音：

1. 改 `index.html` 裡的台詞。
2. 用瀏覽器打開 voice-studio-app 的 `pc/語音專案編輯器.html`，開啟 `voice-project/桃園市龍山國小之校園安全時光機 Episode 2.voiceproj.json`，改成相同的文字（唸法、情緒也可以一起調整），下載後覆蓋原檔。
3. 重新匯入 App（同一個專案，只有改過的句子需要重錄），產生、匯出、套用。

## 注意事項

- **模型授權**：角色模型的 VRM 授權設定為「不允許再散布」。Public repository 裡的檔案任何人都能下載，請確認這符合你的意願。
- **照片**：`index.html` 內含學校的全景照片。
- **語音模型** Qwen3-TTS 採 Apache 2.0 授權，可以用在教學與公開網站。
- **學生進度**（徽章）只存在各自的瀏覽器裡，換裝置或清除瀏覽資料就會重來。
- **修改台詞**需要同時改 `index.html` 和語音專案檔，再重錄語音（見上方）。
